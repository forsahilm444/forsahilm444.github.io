## Tasks Completed

1. `mkdir test_dir` - Create directory
2. `touch test_dir/example.txt` - Create empty file
3. `mv example.txt renamed_example.txt` - Rename file
4. `cat /etc/passwd` - Display file contents
5. `head -n 5 /etc/passwd` - Display first 5 lines
6. `tail -n 5 /etc/passwd` - Display last 5 lines
7. `grep root /etc/passwd` - Search for pattern
8. `zip -r test_dir.zip test_dir` - Compress directory
9. `unzip test_dir.zip -d unzipped_dir` - Extract archive
10. `wget <url> -O sample.txt` - Download file
11. `chmod 444 secure.txt` - Set read-only permissions
12. `export MY_VAR="Hello, Linux!"` - Set environment variable
